## Composition notes

- Spine: Discovery (`spike`, `decide`) then Flow (`tracer-bullet`, `increment`) with `harden`, `release-gate` and `release` for the extract phase.
- Merged: `frame-the-question` into `spike` (the question is written in the first step); `slice` into `increment`; `ship` into the "Land through a pull request" principle plus `release`; `production-readiness` into `release-gate`.
- Pruned: `qa-exploratory` and `regression-suite` (the regression test belongs to `bug-fix`, test first), `pause-and-resume` (the runtime keeps run state across sessions), `incident` (add by Evolve after the first release), `data-dependence` and `perceptual-output` facets (no learned behavior; the Web UI is not judged by golden images yet), `measured-outcome` (an agent-evaluation harness is deferred until the first tracer shows what to measure).
- `decide` carries a human gate although the failure cost is customer: it fixes the core abstraction, the costliest decision to reverse.
- `contract-change` removal is a human gate, not an `[irreversible]` step: the irreversible act is publishing, which `release` guards.
- Playbook count is 14, above the target of 12 and below the limit of 15; `refactor`, `retro` and `add-source` are the first candidates to merge if the graph proves heavy.
- `team: solo` today. When contributors arrive, run Evolve to add contribution and triage playbooks.
- The security review is a work playbook feeding `release-gate`, not a gate itself: a gate must promote a lifecycle or guard an irreversible step.
